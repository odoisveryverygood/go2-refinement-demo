Fewer calls are useful only if the robot still finishes.

The blue box moves while the planner is working. Both methods use the same movement checker. Frequent checking asks the local vision model whenever it is idle; selective checking asks when the active movement is no longer useful.

In this pair, frequent checking succeeded. Selective checking made fewer local calls, but stopped at 0.926 m, outside the fixed 0.9 m arrival limit. This is a failed task, not evidence of preserved performance.

Move each slider to inspect the saved camera frames. The two runs have different durations. Positions are used for scoring, not supplied to the vision models. One warm-up call per local model is recorded separately.

The checker uses a known-color tracker and idealized range geometry. A tracker-only control reached the box without any model calls. This fixture cannot establish that an LLM is necessary, and the local VLM is not a reproduction of a published trained action refiner.
